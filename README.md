# C and C++ practice exercises

A collection of small exercises kept together for practice and revision.

## Folders

- `BIGINT/`: large-integer exercise
- `VECT2/`: two-dimensional vector exercise
- `POLYSET/`: polynomial / set-related exercise
- `BSQ/`: biggest-square problem
- `LIFE/`: Game of Life exercise

Each folder is an independent exercise with its own source files. Check the files in the relevant directory for build instructions and expected input.

These are learning implementations, not packaged applications.
